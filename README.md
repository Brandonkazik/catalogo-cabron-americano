# Fotos del catálogo

Acá están las fotos de la web del catálogo, comprimidas para que carguen rápido.

Cada foto se ve con un link así:

https://brandonkazik.github.io/catalogo-cabron-americano/fotos/LINEA/MODELO/1.jpg

- `fotos/<línea>/<modelo>/1.jpg … 5.jpg`: las fotos de cada modelo, en el orden de FOTO 1 a FOTO 5 del Sheet.
- `fotos/portadas/<línea>.jpg`: la imagen de portada de cada línea.
